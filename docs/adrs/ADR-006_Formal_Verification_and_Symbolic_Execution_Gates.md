# ADR-006: Formal Verification & Pre-Deployment Safety Gates

## Status
Accepted

## Context
Syntactically correct patches generated by LLMs could still violate safety invariants or break API contracts in production.

## Decision
Enforce a formal verification pipeline (`src/verification/`) prior to deployment:
- Function and API contract validation (`EngineeringContract`, `PreCondition`, `PostCondition`).
- AST semantic equivalence checking (`SemanticEquivalenceValidator`).
- Symbolic execution path analysis (`SymbolicExecutor`).
- Deployment safety risk scoring (`RiskAssessmentEngine`).

## Consequences
- Blocks logical regression patches before pull request creation or staging deployment.
